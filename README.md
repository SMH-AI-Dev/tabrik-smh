## ▶️ اجرای سریع
- **ویندوز (ساده):** دابل‌کلیک روی `windows\Tabrik-SMH.bat` یا `python windows\run_windows.py` — برنامه در مرورگر باز می‌شود (آفلاین).
- **ویندوز (دسکتاپ):** `cd windows && npm install && npm start` (Electron).
- **اندروید:** راهنمای `android\README_ANDROID.md` (نصب PWA در ۲ دقیقه).
